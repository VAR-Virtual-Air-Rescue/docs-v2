# Region

Die VAR hat Stationen in **sieben Ländern**. Das ist kein Detail: In jedem ist
der Rettungsdienst anders organisiert, und die Unterschiede reichen bis in den
Funk.

| Land | Stationen | | Land | Stationen |
|---|---:|---|---|---:|
| Deutschland | 97 | | Italien (Südtirol) | 4 |
| Österreich | 44 | | Luxemburg | 3 |
| Schweiz | 24 | | Liechtenstein | 1 |
| Niederlande | 5 | | | |

Gezählt aus dem Stationsbestand der Leitstelle, Stand 29.08.2026 — die Karte
dazu steht unter [Luftrettungszentren](/luftrettung/luftrettungszentren).

::: pruefen Belgien oder Italien?
Die [FAQ](/faq) nennt **Belgien** als Einsatzgebiet und **Italien** nicht. Im
Stationsbestand ist es genau umgekehrt: keine belgische Station, dafür vier in
Südtirol und eine in Liechtenstein. Eines von beidem gehört nachgezogen.
:::

Bis August 2026 gab es hier nur die Schweiz. Der Rest fehlte — obwohl dort der
größte Teil der Einsätze läuft.

## Was sich von Land zu Land unterscheidet

| | Worum es geht |
|---|---|
| **Träger** | Wer betreibt die Hubschrauber — Automobilclub, Stiftung, Behörde, privates Unternehmen |
| **Funkrufnamen** | „Christoph“, „Christophorus“, „Rega“, „Lifeliner“ — jedes Land hat sein eigenes Schema |
| **Leitstellenstruktur** | Wer alarmiert, und nach welchem Zuständigkeitsgebiet |
| **Notrufnummer** | Wer wo aufläuft |
| **Klinikstruktur** | Welche Häuser was können und wie sie benannt sind |
| **Sprache** | In Luxemburg, Südtirol und der Schweiz mehrsprachig — im VAR-Betrieb wird trotzdem deutsch gefunkt |

Die Schweiz ist bislang das einzige ausgearbeitete Kapitel und dient den anderen
als Vorbild — besonders das **Spitallexikon**, das es für die übrigen Länder
noch nicht gibt.

## Was hier nicht steht

Die **Stationen selbst**. Welche Standorte im VAR-Betrieb existieren, mit
welchen Mustern und welchen Fähigkeiten, gehört in die
[Luftrettungszentren](/luftrettung/luftrettungszentren) — dort steht heute noch
ein Platzhalter.

::: pruefen Mitarbeit erwünscht
Wer eines der Länder kennt — beruflich oder aus Interesse — kann hier am meisten
beitragen. Was gebraucht wird, steht auf jeder Länderseite als Liste.

Wie das geht, steht unter [Mitwirken](/mitwirken).
:::
